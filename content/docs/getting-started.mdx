## Before you begin

- **Node.js:** use **20.x or newer** (LTS recommended).
- **Package manager:** use **Bun** or **npm**.

## Option A — Create a new project (recommended)

```bash
npx create-agent-driven-app my-app
cd my-app
bun install
bun dev
```

The CLI asks which optional features you want, then scaffolds a trimmed project.

## Option B — Clone and configure in place

```bash
git clone git@github.com:rashedxali/agent-driven-development.git
cd agent-driven-development
bun install
bun run setup
bun dev
```

### Non-interactive setup

```bash
bun run setup -- --yes
bun run setup -- --no-fumadocs --sentry --infisical
bun run setup -- --force --yes    # re-run; clears .next/
```

Available flags: `--husky`, `--lighthouse`, `--github-ci`, `--fumadocs`, `--agent-tooling`, `--sentry`, `--storybook`, `--infisical` (prefix with `--no-` to disable).

## Optional features

| Feature | Default | Description |
|---------|---------|-------------|
| Husky + Commitlint | on | Git hooks for lint, typecheck, commit format |
| Lighthouse CI | on | Performance, a11y, and SEO audits |
| GitHub Actions | on | Lighthouse workflow on pull requests |
| Fumadocs | on | Documentation site at `/docs` |
| Agent tooling | on | Cursor/Claude skills and AI workflow |
| Sentry | off | Error monitoring with Session Replay |
| Storybook | off | Component stories and Chromatic deploy |
| Infisical | off | Secret management for local dev scripts |

## Run the development server

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

### Infisical (when enabled)

1. Run `infisical init` once at the project root.
2. Add secrets in [Infisical Cloud](https://app.infisical.com).
3. `bun dev` injects secrets as `process.env`.
4. `bun run dev:build` and `bun run dev:start` wrap build/start with Infisical for local prod preview.
5. Plain `bun run build` and `bun run start` are used by CI — no Infisical wrapper.

Use the `NEXT_PUBLIC_` prefix for client-exposed secrets.

## Scripts

```bash
bun dev              # dev server (Infisical-wrapped when enabled)
bun run dev:build    # local prod build with secrets (Infisical only)
bun run dev:start    # local prod server with secrets (Infisical only)
bun run build        # production build — CI / Husky
bun run start        # serve production build
bun run lint
bun run typecheck
bun run perf         # build + Lighthouse CI (when enabled)
bun run setup        # interactive feature selection
```

## Styling

- **App:** `app/globals.css` — Tailwind v4 theme tokens and shadcn styles.
- **Docs:** `app/docs/docs.css` — separate Fumadocs stylesheet (only loaded on `/docs` routes).

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Weird Next / TS errors after branch switch or `setup --force` | Delete `.next/`, reinstall, re-run `bun run build` |
| `instrumentation.ts` not found after disabling Sentry | Delete `.next/` — stale Sentry cache |
| Infisical / `dev` fails | Run `infisical init`, log in, verify secrets exist |
| Port 3000 in use | `PORT=3001 bun dev` |
| Wrong Node version | Switch to Node 20+ via nvm / fnm / volta |
